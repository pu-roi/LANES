## Preserved Windows preflight

From the laptop checkout, verify these manifests against the frozen private preparation records before passing their SHA-256 values:

```powershell
$modelManifest = '.\backend\training\flood_ner\artifacts\v19-evaluation-coordination-20261018-v20\scoped\MANIFEST.json'
$resourceManifest = '.\backend\training\flood_ner\artifacts\v19-development-diagnosis-20261018-v20-run03\seed-0\runtime-model-contract.json'
$modelHash = (Get-FileHash -LiteralPath $modelManifest -Algorithm SHA256).Hash.ToLowerInvariant()
$resourceHash = (Get-FileHash -LiteralPath $resourceManifest -Algorithm SHA256).Hash.ToLowerInvariant()
py -3 -B .\backend\training\flood_ner\runtime_preflight.py `
  --model-manifest $modelManifest --model-manifest-sha256 $modelHash `
  --resource-manifest $resourceManifest --resource-manifest-sha256 $resourceHash `
  --resource-dir .\backend\training\flood_ner\artifacts\preflight-use-20261015\model `
  --interpreter (Resolve-Path .\backend\.venv\Scripts\python.exe).Path `
  --docker 'C:\Program Files\Docker\Docker\resources\bin\docker.exe' `
  --probe-vectors
```
