# V37 contextual representation clarification

> **Last Updated:** October 19, 2026, 8:05 PM Asia/Manila by [@roicambe](https://github.com/roicambe) (Roi Cambe)

This source-only clarification is frozen for the v37 offline study. It supplements the [historical acceptance specification](ner-interim-context-acceptance.md), which remains unchanged. It does not alter production schemas, admitted data or model labels. [Executed outcome](../evaluations/flood-ner-context-grouping-20261019/README.md).

- Separate source observations retain their own exact targets, expressions, evidence and temporal scope. Equal status/access values alone do not justify merging observations.
- Shared means a common supported assertion applies to several independently named targets. Separate paragraph predicates do not become one shared event merely because both say “active.”
- A junction or joint road-portion observation remains collective for depth, status, access and time. The relation does not establish whole-road geometry or identical independent scalar depths.
- Depth-fact semantics and relation-group scope are distinct. A verbal point gauge or maximum can have a collective relation without inventing measurements for each member. Ranges remain ranges.
- A null multirow depth inventory binds its original source-list constituents. It is not a new measurement, common event, clock, status or access rule. Preserve each original row and its updates; never turn null into a scalar.
- Redundant synthesized cross-row access inventories remain explicitly unassigned when their supported information is represented by separate actual source observations. Old-to-new reference mappings must account for them.
- Preserve original text, all entity objects, language, identity, source and partitions. Retained/split facts preserve qualifiers and temporal roles. Every prior association needs a retained/corrected/unresolved disposition before repair implementation.
- Repeated names remain exact occurrences. A parent, causal facility, evacuation site, caption or speaker title does not automatically inherit flood facts. Full-article context may inform source review but cannot be fabricated in a passage-only worker input.
- Unknown targets/roles stay unresolved or unassigned; missing references are never genuine negatives. Existing held objects stay held until separately supported review is authorized.

Strict scoring still binds exact expression/target occurrences, labels, values, depth semantics, time roles and intact relation groups. No fuzzy equivalence, collective flattening or post-result reference change is allowed. Publish previous-encoding and revised-encoding scores separately; reference corrections are not model improvement.

The schema already permits a null collective fact. The successor validator explicitly checks its multiple source-exact constituents while preserving the older validator unchanged. The raw worker envelope and location-only model are unchanged. Constructed checks are software evidence, not human gold or real-world three-language accuracy. Learned DEPTH/TIME remains unfinished.
