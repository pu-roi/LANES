## Root causes and correction

1. **Carriageway ambiguity was mistaken for arbitrary bounds.** Four candidates were two adjacent named junction-to-junction sections, each with two mapped carriageways. Setting `bounded_road_section = not ambiguous_carriageway` conflated lane uncertainty with unbounded geometry. Candidate evidence is now retained, while close parallel carriageways sharing both named and spatially matched endpoints can form a single bounded estimated road corridor. A third branch, crossed lines, missing modeled coverage, mismatched anchors or excessive separation remain unresolved.
2. **Separate lane margins overlapped.** Eligible paired carriageways retain their exact source cores and one dissolved policy margin. Their coordinates are not snapped, averaged into a median, or extended. One source has a 3.86 m modeled gap while its companion supports the full mapped section. The gap remains in that solid core; the supported companion permits the shared outer corridor. A gap across both carriageways is still rejected. Grouping is limited to explicitly audited `passable_all` claims, preventing uncertain lanes from becoming a two-way closure.
3. **An improved extraction was suppressed as a stale observation.** Run 65 changed only `placement_preview` compared with the previous Boni claim, with the same immutable article input and flood facts. Publication compared equal observation times using the superseded-observation branch. It now refreshes the existing automatic text-alert case when the immutable input, source spans, location, time, condition, depth and access match. Expiry cannot increase. Newer observations, clearance, expiry, staff withdrawal and existing Active Zones remain protected; retries cannot create another incident zone.
4. **The review queue checked only the new source's original case.** Reprocessed evidence can be consumed by an existing incident case. The queue now checks that consumer case's latest decision too, preventing an obsolete source-case exception from displaying resolved work as Needs Review.
