Metro Manila modeled flood-hazard display images

Source: Project NOAH flood hazard polygons, Metro Manila 5-, 25-, and
100-year scenarios, distributed through BetterGov.PH:
https://huggingface.co/datasets/bettergovph/project-noah-hazard-maps

Source license: Project NOAH Open Data License / Open Data Commons Open
Database License (ODbL) 1.0:
https://huggingface.co/datasets/bettergovph/project-noah-hazard-maps/resolve/main/NOAH_License.pdf

Derived display images are shared under the same ODbL 1.0 terms. Credit:
Project NOAH and its contributors. These images are a rasterized visual
representation of modeled hazard classes, not current flood observations
or analytical road-intersection geometry. Source-map vintage has not yet
been verified.

Regenerate with backend/scripts/export_noah_hazard_overlay.py using the
three locally inspected Metro Manila NOAH ZIP archives. Colors are
Var=1 yellow (low), Var=2 orange (medium), Var=3 red (high).
